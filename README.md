# SW — Studio West

Исходники темы и контента сайта [studiowest.ru](https://studiowest.ru): MODX-шаблоны, CSS/JS, сниппеты, SEO-тексты.

## Структура

| Папка | Назначение |
|-------|------------|
| `shablon/` | HTML-шаблоны MODX (главная, кейсы, оплата, SEO-лендинги) |
| `css/` | `sw_main.css`, стили песочницы |
| `js/` | `sw.js`, формы, оплата, listing |
| `snippet/` | PHP-сниппеты (оплата, sitemap, FAQ schema) |
| `pic/` | Изображения для плиток и фонов |
| `sitestatistics/` | Компонент MODX (Метрика) |
| `assets/pay/` | Заготовки каталогов заказов/счетов (данные не в git) |

## Деплой

На прод файлы копируются в `/var/www/studiowest.ru/public/assets/teme_sw/`. Шаблоны и контент — через MODX (ресурсы, чанки, TV).

Доступ к серверу — локальный файл `env` (не в репозитории).
