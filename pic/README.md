# Картинки studiowest.ru (`/pic/`)

Два типа фонов — разный цвет и назначение. Не смешивать.

## `*-fon.jpg` — первый экран страницы

**TV MODX:** `fonSite`  
**Где:** блок `.anons` (шаблон `Information.html`, AJAX через `FON` в `request.php`)

### Эталон стиля (не менять)

Образец — **`landing-fon.jpg`**, **`corporate-fon.jpg`**, **`shop-fon.jpg`**:

- **Фотореализм**, тёплый оранжевый свет (`#E77817`, `#f93`)
- **Одна тематика на раздел** — сюжет совпадает с услугой
- Если на фото есть экран — **оранжевый UI-макет** под тему
- ~1152×768 (или пропорционально шире), shallow DOF

**Ноутбук / монитор — не обязателен.** Это фишка раздела «сайты / что делаем» (лендинг, корпоратив, магазин, хаб «Сайты»). В других разделах — свой реалистичный сюжет: брать на основе старого фона, главное — **оранжевая гамма и фото, не иллюстрация**.

Все новые `*-fon.jpg` — в **этой** палитре и качестве, не синие.

## Component SW — свой продукт студии

**Не услуга «под заказ»**, а **UI-библиотека Studio West** (веб-компоненты, светлая/тёмная тема).

| | |
|---|---|
| **Сайт** | раздел `/component-sw/` (ресурс MODX **id=45**, дочерние — Button, Input, …) |
| **npm** | `@studio-west/component-sw` — README и пакет на [npmjs.com](https://www.npmjs.com/package/@studio-west/component-sw) |
| **GitHub** | `studio-west/component-sw` — **закрытый** репозиторий; на сайте секции README подтягиваются сниппетом `NpmReadmeSection` (npm или raw GitHub при доступе) |
| **Песочница** | `code-sandbox.js`, `sandbox-boot.js` — превью компонентов через unpkg |

### Картинки раздела

| TV | Файл | Примечание |

Для новых `*-fon` / `*-pl` Component SW: **не смешивать с коммерческими «сайтами»** — сюжет про код, UI-kit, документацию; на главной плитка может быть синей (как остальные `*-pl`), hero — в оранжевой гамме `*-fon`, если страница на `Information.html`.

### SEO

- Хаб `/component-sw/` — витрина продукта (sitemap **0.5**, index). Не конкурирует с «Сайты» (0.8).
- Дочерние доки компонентов — `searchable=0` → `noindex,follow`, из sitemap исключены.
- Не дублировать npm README 1:1 на хабе: уникальный текст + `NpmReadmeSection` только для установки.
- Анонс в журнале `/journal/component-sw` ссылается на хаб, не подменяет документацию.
